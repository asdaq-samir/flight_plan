Flying this leg, would I look up and know that’s the one — not one like it?
0 Not a feature. Contour, boundary, chart border. The detector is wrong.
1 Real, but you’d never use it. One creek among a dozen.
2 You’d have to hunt, and might not be sure you found it.
3 Workable. Findable, but confusable with something nearby.
4 You’d expect to spot it and be confident.
5 Unmistakable. On the nav log without a second thought.
0 vs 1 matters most. 0 means the detector should never have surfaced it; 1 means it’s a real feature that’s just poor. They fix different things.

DR vs visual. DR is a checkpoint you fly over — it fixes time and position and becomes a nav-log leg, so it has to be on course. Visual is a reference you see out of the side window to confirm you are where you think. Off course is fine, and often the point. The toggle defaults from how far off course the point sits; override it freely.
