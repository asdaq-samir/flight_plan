# wingtip's own runtime dependencies: the one place they are listed, and the
# one place each is pinned. Every image that runs wingtip installs this file
# (planning-service, pipeline-processing, pipeline-training, ml), and so
# does the test suite, each through a `-r` line in its own requirements
# file -- which then lists only what that image needs on top.
#
# It used to be the other way round: each image repeated wingtip's imports,
# with a comment tracing the import chain, and a new import in wingtip was a
# new line in six files. On 2026-09-22 wingtip.geo moved to PROJ and only
# planning-service's file was updated; both agents and both pipeline
# stages then failed on import, and nothing showed it until they were
# restarted.
#
# A new third-party import in src/wingtip belongs here -- or in
# requirements-charts.txt if only wingtip.charts/wingtip.chartvision need it.
# The CI build job imports what each service imports inside its built
# image, so a missing line fails there rather than on a restart.
#
# Pinned to what python:3.14-slim resolves; Dependabot keeps the pins
# moving (.github/dependabot.yml watches /src).
numpy==2.5.3        # wingtip.geo, wingtip.features, wingtip.osm, wingtip.weather
pandas==3.0.6       # wingtip.airports, wingtip.faa_data, wingtip.features, wingtip.pipeline
requests==2.34.2    # every external source (wingtip.retry)
cachetools==7.2.1   # wingtip.sua's day cache of special-use airspace; planning-service's own caches
pyarrow==25.0.1     # wingtip.faa_data's Parquet cache of the obstacle table; the pipeline's feature store
shapely==2.1.2      # wingtip.airspace polygons, wingtip.weather's hazards, wingtip.osm's representative points
pyshp==3.1.6        # wingtip.airspace reads the FAA Class Airspace shapefile
pyproj==3.8.0       # wingtip.geo -- PROJ's distance/azimuth, scalar and vectorised over a whole corridor
pydantic==2.13.5    # pinned once here for planning-service's FastAPI and its schemas
pydantic-settings==2.16.2   # wingtip.config's Settings -- every environment variable wingtip and the planner read

pygeomag==1.1.0     # the oracle tests/test_flight_rules.py holds the engine's WMM-2025 (wingtip.magnetic) to
astral==3.2         # wingtip.sun -- civil twilight, which sets the night fuel reserve
