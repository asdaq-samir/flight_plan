# vfr's own runtime dependencies: the one place they are listed, and the
# one place each is pinned. Every image that runs vfr installs this file
# (planning-service, pipeline-processing, pipeline-training, ml), and so
# does the test suite, each through a `-r` line in its own requirements
# file -- which then lists only what that image needs on top.
#
# It used to be the other way round: each image repeated vfr's imports,
# with a comment tracing the import chain, and a new import in vfr was a
# new line in six files. On 2026-09-22 vfr.geo moved to PROJ and only
# planning-service's file was updated; both agents and both pipeline
# stages then failed on import, and nothing showed it until they were
# restarted.
#
# A new third-party import in src/vfr belongs here -- or in
# requirements-charts.txt if only vfr.charts/vfr.chartvision need it.
# The one exception is vfr.narrative's pydantic: only the two agents
# import that module, and both install pydantic through their own
# frameworks.
# The CI build job imports what each service imports inside its built
# image, so a missing line fails there rather than on a restart.
#
# Pinned to what python:3.13-slim resolves; Dependabot keeps the pins
# moving (.github/dependabot.yml watches /src).
numpy==2.5.3        # vfr.geo, vfr.features, vfr.osm, vfr.weather
pandas==3.0.5       # vfr.airports, vfr.faa_data, vfr.features, vfr.pipeline
requests==2.34.2    # every external source (vfr.retry), vfr.model_client, vfr.planner_client
pyarrow==25.0.1     # vfr.faa_data's Parquet cache of the obstacle table; the pipeline's feature store
shapely==2.1.2      # vfr.airspace polygons, vfr.weather's hazards, vfr.osm's representative points
pyshp==3.1.6        # vfr.airspace reads the FAA Class Airspace shapefile
pyproj==3.8.0       # vfr.geo -- PROJ's distance/azimuth, scalar and vectorised over a whole corridor
scipy==1.18.1       # vfr.geo's cluster_points KD-tree (imported at vfr.geo's module level)
pygeomag==1.1.0     # vfr.magnetic -- the World Magnetic Model, evaluated locally
astral==3.2         # vfr.sun -- civil twilight, which sets the night fuel reserve
