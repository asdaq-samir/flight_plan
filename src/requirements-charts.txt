# wingtip.charts and wingtip.chartvision: reading, rendering and segmenting the
# FAA's chart rasters, on top of wingtip's own list -- and wingtip.publications,
# which draws the FAA's airport diagrams, and wingtip.glmp, which reads the
# NWS's gridded weather. Only the images that
# draw or read charts install it -- planning-service and the test suite
# -- which keeps rasterio's bundled GDAL out of the pipeline images.
-r requirements.txt
pillow==13.0.0      # wingtip.charts encodes the tiles, wingtip.chartvision reads them
rasterio==1.5.2     # wingtip.charts reads and reprojects the FAA chart GeoTIFFs (bundles GDAL; the slim image needs libexpat1 for it)
pypdfium2==5.14.0   # wingtip.publications draws the airport diagram's PDF as a picture (Apache-2.0/BSD; PyMuPDF is AGPL)
affine==3.0.1       # wingtip.chart_faces applies transforms with `@`, which affine 3 has; it came only as rasterio's own, unpinned, dependency
gribberish==1.9.0   # wingtip.glmp reads the NWS's Gridded LAMP (GRIB2), complex packing included (MIT; 2 MB, where eccodes is 100)
